深淵樹迷宮 v3.10.9.2 START FLOW LOCK

問題
- 探索中にブラウザを更新すると「続きから」と「新しい探索を始める」の両方が表示されていた
- 新しい探索を選ぶことで、死亡・帰還を経ずに第1層へ戻る経路が存在した
- 装備喪失、帰還判断、探索リセットのバランスを壊していた

新しいタイトル画面
初回
- 「灯台から始める」だけ表示
- 第1層へ直接入らない
- 最初の武器は灯台から出発する際に選択

探索中の保存あり
- 「探索を再開」だけ表示
- 新しい探索ボタンを非表示
- 階層、HP、充足、装備、敵、アイテム、ターンを維持
- 第1層へ無条件で戻る経路を廃止

灯台の保存あり
- 「灯台へ戻る」だけ表示
- 灯台を復元後、灯台内から次の探索を開始

正規の探索開始
- 灯台の「新しい探索を始める」だけ
- 保険、持込装備、迷宮反応などの出発処理を必ず通る

ゲームオーバー後
- 「灯台へ戻る」
- タイトルから直接再挑戦しない

破損した探索保存
- 探索保存とバックアップを削除
- 永続メタデータだけを使って灯台へ退避
- 進行中探索の装備・現地取得物は持ち越さない
- 装備を保持したまま第1層へ戻る救済処理は行わない
- 退避理由を画面に表示

旧セーブ
- 探索中保存はそのまま再開
- 灯台保存はそのまま灯台へ復元
- 永続装備、姿、倉庫、研究、携行糧強化などを維持
