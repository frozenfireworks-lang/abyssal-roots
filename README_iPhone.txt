深淵樹迷宮 v3.10.3.2 STAIR RETURN HOTFIX

不具合の原因
- 帰還楔の条件が「階段マスの上に立つ」になっていた
- 階段マスへ入ると即座に次階層への確認が始まるため、その場に留まれなかった
- 結果として通常操作では帰還楔を使用できなかった

修正後の使い方
1. 帰還楔を1個以上所持
2. 現在階の階段解放条件を達成
3. 解放済み階段の上下左右いずれかへ移動
4. メニューの「帰還」を押す
5. 帰還楔を1個消費して灯台へ帰還

判定
- 階段の上下左右：使用可能
- 階段の斜め隣：使用不可
- 階段から2マス以上：使用不可
- 階段マスへ入る：従来どおり階層移動確認

番人撃破後
- 番人階の階段へ上下左右で隣接すると無料帰還可能
- 帰還楔は消費しない
- 階段へ入れば進路選択または次階層移動

祭壇
- 従来どおり祭壇マスの上から帰還
- 帰還楔は消費しない

旧セーブ
- セーブ形式の変更なし
- 進行中探索にも隣接判定を即時適用
- 装備、倉庫、保険、遺響、刻印、共鳴、迷宮反応を維持
