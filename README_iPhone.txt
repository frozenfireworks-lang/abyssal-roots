深淵樹迷宮 v3.20.0 LIVING FLOORS

ゲーム全体の改善方針
- 通常階が生成された瞬間の状態のまま終わる問題を改善
- 探索途中で迷宮そのものが変化する「迷宮現象」を追加
- 発生は通常階の一部だけ。番人階・休息階・序盤2層には出さない
- 現象内容と発生手数は階生成時に探索ID+階層から固定し、再読込で引き直せない
- 発生3手前から短い兆候を表示し、突然の即死要素にはしない

迷宮現象
1. 闇潮
- 10手
- 視野-2
- 敵の索敵距離-2
- 見えにくい代わりに敵もこちらを捉えにくい

2. 灯脈噴出
- 8手
- 視野+2
- 敵の索敵距離+2
- 現象中は灯油を消費しない
- 周囲そのものが明るいため暗闇命中ペナルティを受けない

3. 深層静穏
- 10手
- 通常敵の再出現を停止
- 移動/構えによる気力回復+1
- 一時的な立て直し時間

4. 地脈震動
- 発生時に崩れ石・絡み根を新たに生成
- 通常敵の攻撃予兆を解除
- 通常敵を1行動よろめかせる
- 階の途中で盤面の戦術地形が変化

5. 生態流入
- 遠方から死者・獣群・異形のいずれかが3〜4体流入
- 優勢勢力が存在する場合は、その勢力が流入しやすい
- 流入個体はプレイヤーの方向へ移動開始
- 全滅させると深淵の欠片+1
- 死者：鑑定紙片+1
- 獣群：携行糧+45
- 異形：灯油+1
- 無視して階段へ進むことも可能

UI
- 発生3手前から階層目標に「兆候」を表示
- 発生中は現象名と残り手数を表示
- 生態流入は残存個体数を表示
- 探索結果に経験した現象と収束回数を記録

保存互換
- 旧保存の現在階には現象を後付けしない
- 次に新規生成される対象階から開始
- 進行中の現象は通常の探索保存へ含まれ、再開後も残り手数・流入個体を維持

バランス
- 既存の敵基本能力、ドロップ率、充足、特異室、深脈分岐、戦術地形、番人性能は変更なし
