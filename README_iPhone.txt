深淵樹迷宮 v3.10.5.2 LAST STAND RENEWAL

踏み止まりの強化
旧効果
- 致命傷をHP1で耐える
- 残りの敵行動を中断
- 気力を0にする
- 3行動の衰弱
- 探索中1回だけ

新効果
- 気力5を消費して次の敵行動へ構える
- 致命傷を受けた時だけ発動
- HPを最大HPの25%まで立て直す
- 発動時に気力を3回復
- 残りの敵行動を中断
- 同じ敵行動中は追加ダメージを受けない
- 衰弱を3行動から2行動へ短縮
- 発動しなかった場合も使用済みになる

番人撃破による回復
- 番人を倒すと踏み止まりが残り1回へ回復
- 使用済みなら再使用可能になる
- 未使用なら残り1回を維持
- 2回分を蓄積することはできない
- 構え中に番人が倒れた場合は、現在の構えが解けた後に残り1回へ回復
- 炎上や地形効果で構え中の番人が倒れても、使用回数が二重に残らないよう処理

確認画面
表示内容
- 現在HP
- 固定予測被害
- 発動後に保証される最低HP
- 気力5を消費した直後の気力
- 最大HP25%への立て直し
- 気力+3
- 残りの敵行動中断
- 2行動の衰弱
- 番人撃破で残り1回へ回復
- 上限1で蓄積しないこと
- 致死予測の有無
- 発動しなくても使用済みになる警告

操作
1. 「踏み止まり」を押す
2. 確認画面で効果と現在値を確認
3. 中止なら「戻る」
4. 実行なら「気力5で構える」

旧セーブ
- セーブ形式の変更なし
- 使用済み・構え中・衰弱状態を維持
- 番人撃破回復の待機状態を追加
- 装備、倉庫、保険、遺響、刻印、共鳴、迷宮反応、灯台調律を維持
