深淵樹迷宮 v3.12.0.1 AUDIO STABILITY

目的
v3.12.0で追加したケルト調BGMと効果音を、iPhoneで長時間動かしても重複・音割れ・タイマー蓄積が起きない構造へ更新しました。

BGMの2レーン構成
- 音楽レーンA
- 音楽レーンB
- BGMダッキングバス
- BGM音量バス
- マスターコンプレッサー

場面変更時
1. 使用していないレーンの予約音を停止
2. 新しい場面を未使用レーンへ予約
3. 古いレーンを約0.72秒で消音
4. 新しいレーンを約0.72秒で上昇
5. クロスフェード後に古い音源を停止

対象の切替
- タイトル / 灯台
- 通常探索と各バイオーム
- HP30%以下または固定予兆2件以上
- 番人戦
- 死亡

同じ場面でrenderが繰り返されても、音楽タイマーは1本だけです。

予約音の管理
- BGM用OscillatorとBufferSourceをレーンごとに記録
- 場面変更時に古い予約音を停止
- バックグラウンド移行時に全レーンを即停止
- 終了した音源はonendedで一覧から削除
- スケジューラが遅れた場合は過去の小節を連続生成せず、現在時刻へ追従
- 1回のスケジューラ処理で最大3小節まで

効果音の同時発音制限
最大22音です。

上限へ達した場合
- 新しい音より優先度の低い古い音を停止
- すべて高優先音なら、新しい低優先音を再生しない

優先度例
低
- 足音
- メニュー音
- 通常攻撃

中
- 命中
- 被弾
- 回復
- エリート撃破

高
- 会心
- レア入手
- 爆発
- 番人出現
- 番人撃破
- 死亡
- 魂還石

短時間連打の間引き
同じ効果音へ種類別の最短間隔を設定しました。
- 足音 52ms
- 命中 18ms
- 爆発 80ms
- 番人撃破 350ms
- 死亡 500ms

ゲーム処理やダメージ回数は変更しません。音だけを間引きます。

BGMダッキング
重要な効果音の瞬間だけBGMを短く下げます。
対象例
- 会心
- 被弾
- 爆発
- 番人
- 番人撃破
- 死亡
- 魂還石
- 銘装誓約

効果音終了後は自動的に元のBGM音量へ戻ります。

バックグラウンド
visibilitychange / pagehideで次を実行します。
- 探索保存
- 音楽タイマー停止
- BGM音源停止
- 効果音停止
- AudioContext休止

復帰
pageshow / visibilitychangeで復帰を試行します。
- 現在のゲーム状態からBGM場面を再判定
- 新しい小節の先頭から再生
- iOSが再開を拒否した場合は「画面を一度タップして再開」と表示
- 次のユーザー操作で再開

音OFF / 音量0
BGM OFF
- 音楽タイマーと予約音を破棄

効果音 OFF
- 再生中の効果音を停止

両方OFF
- 全音源を停止
- AudioContextを休止

BGM音量0%
- BGMがON表示でもスケジューラを停止

効果音量0%
- 新しい効果音を生成せず、再生中の効果音も停止

音設定画面
再生状態を追加しました。
- 最初のタップ後に開始
- 稼働中・効果音 N/22
- バックグラウンド停止中
- 画面を一度タップして再開
- BGM・効果音とも停止
- Web Audio非対応

セーブ互換
- 既存のBGM ON/OFF
- 効果音 ON/OFF
- BGM音量
- 効果音量
を維持します。

ゲームバランス
音響処理だけの更新です。
敵、装備、経験、銘装、死亡、保険、遺響の数値は変更していません。
