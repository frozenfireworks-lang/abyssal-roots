深淵樹迷宮 v3.9.1 LIGHTHOUSE LOADOUT

灯台の出撃準備
- 帰還時の装備一式を保存して表示
- 次回出撃時の装備一式を別に表示
- 武器、盾、頭、胴、腕、足、指輪、お守りの8部位に対応
- 両方の装備合計として攻撃、防御、会心、追加充足を表示

次回装備の切り替え
- 倉庫装備の「次回の○○に設定」で部位ごとに変更
- 同じ装備をもう一度押すと持込解除
- 次回装備欄から部位ごとに解除可能
- 「次回装備をすべて解除」を追加
- 「帰還時装備を次回へ設定」を追加
- 同じ部位を選ぶと自動的に入れ替え

継承解除
- 従来の「継承中」を解除できない問題を修正
- 選択中の倉庫装備には「○○を解除」と表示
- 選択装備を分解した場合は次回装備からも自動解除

次の探索
- 次回装備に武器が設定されていれば、スターター武器選択を省略
- 設定済みの全装備を装備した状態で第1層へ出発
- 次回武器がなければ従来どおり初期武器を選択
- 必要レベル2以上の装備は開始Lvで使用できないため選択不可

旧データ
- 従来の継承装備1個を該当部位の次回装備へ自動移行
- 旧セーブデータを維持
