深淵樹迷宮 v3.0 KEYWORD BUILDS

追加内容
- 装備タグ6種類
  炎 / 毒 / 光 / 影 / 骨 / 雷
- レア度に応じてタグ合計が増加
  Common 1 / Magic 3 / Rare 5 / Legendary 8
- 武器と防具のタグを合算
- 各タグ3・6・10で段階効果

主な効果
- 炎：炎上強化、炎上敵への追加ダメージ、撃破時着火
- 毒：毒時間延長、毒ダメージ強化、撃破時感染
- 光：視野拡大、亡者特効、暗闇命中低下無効
- 影：敵感知低下、会心上昇、未警戒への初撃強化
- 骨：防御上昇、被ダメージ軽減、致死攻撃を探索中1回耐える
- 雷：連鎖威力・距離強化、確率硬直

表示
- 装備画面に現在のタグビルド
- 各装備のタグを表示
- 装備交換時にタグ増減を比較
- 倉庫にもタグ表示
- 旧セーブへタグを自動付与
