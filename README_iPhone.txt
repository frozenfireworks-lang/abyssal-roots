- 3.21.0で欠落していた </style> を復元し、画面が暗いまま何も表示されない不具合を修正

目的
- 「探索で偶然見つける」→「失いたくない」→「生還する」→「灯台で開ける」という感情の波を追加
- 単純な報酬量増加ではなく、期待・緊張・開放・余韻を分離する

封印遺物
- 通常敵から極低確率
- エリートは約3.8%
- 宿敵は約14%
- 番人は約30%
- 未発見状態では次に倒す番人が初回の封印遺物を必ず提示
- 特異室制圧後にも低確率で追加出現
- 最大3個まで携行
- 探索中は開封不可
- 死亡すると携行中の封印遺物はすべて喪失
- 生還すると灯台の「封印遺物」へ永久保存

封印の外見
- 灰封：通常敵由来
- 紫脈封：変異個体・特異室由来
- 黒金封：宿敵・番人由来
- 色は期待度の差を示すだけで、中身そのものは開封まで見えない
- 封印は入手順に開けるため、黄金残響を特定の封印へ任意に当てるリセマラを防止

灯台開封
- 開封時に短い静止・脈動演出を挟み、その後に報酬を公開
- 装備報酬は灯台調律済み・鑑定済み・保護状態で倉庫へ入る
- 倉庫が20/20で装備報酬になる封印は、誤消失防止のため開封できない

報酬層
- 希少装備
- 選別遺装：複数候補を内部抽選して良い方
- 伝説装備
- 魂還石
- 深層遺宝：極低確率。深度+3相当で生成した伝説候補3つの中から最良を採用し、専用名称を付与
- 各開封で少量の深淵の欠片も獲得

黄金残響（ゲーム内救済）
- 伝説以上が出なかった開封で +1
- 7/7になると次の開封は伝説以上を保証
- 伝説以上が出ると0へ戻る
- 灯台に進捗を常時表示
- 課金、期限、ログイン日課、取り逃し要素は無し

探索結果
- 封印遺物の発見数
- 生還時の持ち帰り数
- 死亡時の喪失数
を記録

既存セーブ
- meta.sealedRelics / relicFortune が無い場合は自動初期化
- 進行中の旧探索には sealedRelics=[] を補完
- 既存の装備・倉庫・銘装・研究・遺響・生態・深脈などは変更しない

3.25.1 ABYSS WHISPERS
- 初回探索後、灯台の出撃準備で「深淵の囁き」を3択から選べます。
- 条件は既存行動（撃破・反撃・階層目標・装備発見・特異室・番人撃破）だけを利用します。
- 達成して生還すると紫脈封または黒金封の封印遺物を獲得します。
- 達成後に死亡すると報酬は失効し、リスクと生還欲求を作ります。
- 新通貨・別倉庫・別育成軸は追加していません。


3.26.3 ROOT BUILD
- 探索中のレベルアップを「刃脈 / 護脈 / 探脈」の3系統へ再構成
- 通常レベルアップは3系統から1候補ずつ出し、極端なハズレ3択を減らした
- 同じ樹脈を2回・4回選ぶと、その探索だけ追加効果が解放される
- 刃脈：反撃威力+10% → 会心倍率+0.15
- 護脈：防御+1 → 最大気力+1
- 探脈：視野+1 → 通常拾得+1
- 3レベルごとの才能も可能な限り3系統から1つずつ提示し、ビルドの方向を選びやすくした
- 未使用だった才能「勝ち筋」を正式追加（剣で撃破時に気力2回復）
- 樹脈は帰還・死亡でリセットされ、恒久通貨や新しい灯台育成軸は増やしていない
- 探索結果へ最終的な樹脈構成を記録

- 最小文字サイズを全体的に引き上げ、UI全体の可読性を再調整
- 文字サイズの大小関係は維持しつつ、小ラベル・補足文・チップ類を中心に底上げ
- 画面情報量を保ちながら、目を凝らさず読めるバランスへ調整

- UI全体の文字サイズ指定454か所を再査定
- 7px台の極小文字を廃止し、最小9pxを基準に再設計
- 8px台→9.5px、9px台→10px、10px台→10.8pxを中心に段階的に底上げ
- 小文字の行間・チップ・ボタン内文字も合わせて再調整

- 最小文字サイズをさらに大きくし、9px台を11.5pxへ、10px台を12pxへ引き上げ
- 11px台も12.8pxへ底上げして、小さい本文や補足文を実機で読みやすく調整
- タイポグラフィの階層感は維持しつつ、灯台UI全体で「変化を体感できる」水準まで拡大
- 通常階に「連携戦団」を追加。敵の役割を組み合わせた小規模な戦術遭遇が発生
- 1体がプレイヤーを発見すると同じ戦団全体が連携警戒し、個別釣りだけでは崩しにくくなった
- 墓鐘護衛 / 穿ち狩り / 消灯包囲 / 鐘射十字の4編成を深度・バイオーム条件で配置
- 戦団は通常配置を置き換えるため、単純な敵密度増加にはしない
- 戦団撃破は探索内所持金の小報酬と探索記録へ反映。新通貨・新恒久軸は追加しない

- 番人戦利品に固有の「番人刻印」を追加
- 鎖返し：反撃好機+10%、反撃成功で気力1回復
- 断章：予兆中の敵を撃破すると武技CD-2・気力1回復
- 炉心：炎上中の敵への直接ダメージ+20%（重複時最大+30%）
- 静根：敵が見えている時の休息で追加気力回復＋構え獲得
- 既存の番人戦利品も wardenTrophyKey から刻印を自動復元

- プレイヤーが何もしなくても、第1〜3層では約0.72秒ごとに敵側の時間が進む
- プレイヤーの移動・通常攻撃・スキル使用そのものでは敵行動を即発生させない
- 敵の予兆は次のリアルタイム敵行動まで残るため、時間制限付きで回避・構え・態勢崩しを判断する
- プレイヤー移動には約0.135秒、近接攻撃には約0.31秒、弓攻撃には約0.39秒など短い行動硬直を追加
- 方向ボタンは第1〜3層で長押し連続入力に対応。敵へ押し付ける方向を長押しすると行動硬直に合わせて連続攻撃
- 中央の「休息」はリアルタイム中だけ「回避」へ変更
- 回避は最後に入力した方向へ最大2マス移動、気力3、再使用約1.45秒
- 回避直後の約0.43秒は敵からの直接ダメージを回避。罠・崩落など地形ダメージは無効化しない
- 回避は壁・敵・階段を飛び越えないため、位置取りを無視するワープにはしない
- 「集中」ボタンをリアルタイム専用UIへ追加
- 集中は気力2、2.6秒間だけ敵行動間隔を約0.72秒→約1.22秒へ低速化、再使用7秒
- 集中は完全停止ではないため、考えている間にも敵は迫る
- 第1〜3層の敵行動タイミングを小さなゲージで常時表示
- 通常時の敵行動ゲージ、集中中表示、集中再使用までの秒数を同じ小型UIへ集約
- スキル選択・倉庫・ヘルプ・イベント・確認ダイアログなど操作UIを開いている間は、今回の試作では事故防止のため敵時間を停止
- HP/状態異常/敵AI/予兆/地形/生態/クールダウンは独立したリアルタイム敵行動パルスで進行
- 充足と灯火消費は敵行動2回につき1回にし、リアルタイム化だけで資源消費が極端に高速化しないよう調整
- 気力は敵行動パルスごとに1自然回復し、休息ボタンを失う第1〜3層でも行動不能になりにくくした
- 階段上・足元に拾得物がある時は中央ボタンを従来どおり「階段/回収」に戻し、回避ボタンが重要操作を潰さない
- キーボードでは Space=回避、Shift=集中。方向キー/WASDは従来どおり
- タイトルとヘルプをv4試作仕様へ更新し、第1〜3層と第4層以降の違いを明示
- 第4層到達時に新リアルタイム専用UIは自動で消え、中央ボタンも「休息」へ戻る
- 灯台・倉庫・装備・封印遺物・宿敵・遺響・深層・死亡ロスト・第一深度圏などのゲーム本体システムは維持
- リアルタイム案が合わない場合は、保存してある v3.60.0 WARDEN MASTERY の7ファイルへ上書きすれば戦闘実験前へ戻せる
