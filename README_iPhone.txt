目的
- 「探索で偶然見つける」→「失いたくない」→「生還する」→「灯台で開ける」という感情の波を追加
- 単純な報酬量増加ではなく、期待・緊張・開放・余韻を分離する

封印遺物
- 通常敵から極低確率
- エリートは約3.8%
- 宿敵は約14%
- 番人は約30%
- 未発見状態では次に倒す番人が初回の封印遺物を必ず提示
- 特異室制圧後にも低確率で追加出現
- 最大3個まで携行
- 探索中は開封不可
- 死亡すると携行中の封印遺物はすべて喪失
- 生還すると灯台の「封印遺物」へ永久保存

封印の外見
- 灰封：通常敵由来
- 紫脈封：変異個体・特異室由来
- 黒金封：宿敵・番人由来
- 色は期待度の差を示すだけで、中身そのものは開封まで見えない
- 封印は入手順に開けるため、黄金残響を特定の封印へ任意に当てるリセマラを防止

灯台開封
- 開封時に短い静止・脈動演出を挟み、その後に報酬を公開
- 装備報酬は灯台調律済み・鑑定済み・保護状態で倉庫へ入る
- 倉庫が20/20で装備報酬になる封印は、誤消失防止のため開封できない

報酬層
- 希少装備
- 選別遺装：複数候補を内部抽選して良い方
- 伝説装備
- 魂還石
- 深層遺宝：極低確率。深度+3相当で生成した伝説候補3つの中から最良を採用し、専用名称を付与
- 各開封で少量の深淵の欠片も獲得

黄金残響（ゲーム内救済）
- 伝説以上が出なかった開封で +1
- 7/7になると次の開封は伝説以上を保証
- 伝説以上が出ると0へ戻る
- 灯台に進捗を常時表示
- 課金、期限、ログイン日課、取り逃し要素は無し

探索結果
- 封印遺物の発見数
- 生還時の持ち帰り数
- 死亡時の喪失数
を記録

既存セーブ
- meta.sealedRelics / relicFortune が無い場合は自動初期化
- 進行中の旧探索には sealedRelics=[] を補完
- 既存の装備・倉庫・銘装・研究・遺響・生態・深脈などは変更しない

- 初回探索後、灯台の出撃準備で「深淵の囁き」を3択から選べます。
- 条件は既存行動（撃破・反撃・階層目標・装備発見・特異室・番人撃破）だけを利用します。

3.26.3 ROOT BUILD
- 探索中のレベルアップを「刃脈 / 護脈 / 探脈」の3系統へ再構成
- 通常レベルアップは3系統から1候補ずつ出し、極端なハズレ3択を減らした
- 同じ樹脈を2回・4回選ぶと、その探索だけ追加効果が解放される
- 刃脈：反撃威力+10% → 会心倍率+0.15
- 護脈：防御+1 → 最大気力+1
- 探脈：視野+1 → 通常拾得+1
- 3レベルごとの才能も可能な限り3系統から1つずつ提示し、ビルドの方向を選びやすくした
- 未使用だった才能「勝ち筋」を正式追加（剣で撃破時に気力2回復）
- 樹脈は帰還・死亡でリセットされ、恒久通貨や新しい灯台育成軸は増やしていない
- 探索結果へ最終的な樹脈構成を記録

- 最小文字サイズを全体的に引き上げ、UI全体の可読性を再調整
- 文字サイズの大小関係は維持しつつ、小ラベル・補足文・チップ類を中心に底上げ
- 画面情報量を保ちながら、目を凝らさず読めるバランスへ調整

- UI全体の文字サイズ指定454か所を再査定
- 7px台の極小文字を廃止し、最小9pxを基準に再設計
- 8px台→9.5px、9px台→10px、10px台→10.8pxを中心に段階的に底上げ
- 小文字の行間・チップ・ボタン内文字も合わせて再調整

- 最小文字サイズをさらに大きくし、9px台を11.5pxへ、10px台を12pxへ引き上げ
- 11px台も12.8pxへ底上げして、小さい本文や補足文を実機で読みやすく調整
- タイポグラフィの階層感は維持しつつ、灯台UI全体で「変化を体感できる」水準まで拡大
- 通常階に「連携戦団」を追加。敵の役割を組み合わせた小規模な戦術遭遇が発生

- 戦団は通常配置を置き換えるため、単純な敵密度増加にはしない
- 戦団撃破は探索内所持金の小報酬と探索記録へ反映。新通貨・新恒久軸は追加しない

- 番人戦利品に固有の「番人刻印」を追加
- 鎖返し：反撃好機+10%、反撃成功で気力1回復
- 断章：予兆中の敵を撃破すると武技CD-2・気力1回復
- 炉心：炎上中の敵への直接ダメージ+20%（重複時最大+30%）

生成ルール
- 戦技変質は武器にだけ付与
- 通常ルールでは魔法武器55%、希少・伝説武器100%
- 第1〜5層のリアルタイム試作中に生成される魔法以上の武器は、システム評価をしやすくするため100%で1つ付与
- 希少以上へ昇格した武器に戦技変質が無い場合は自動で1つ補完
- コモン武器には付与しない
- スターター武器には付与しないため、変質武器を拾った時に「装備更新で戦い方が変わった」と比較できる
- 一つの武器には現在1種類だけ付く

剣
- 血旋連舞
  - 旋撃で2体以上を巻き込み、1体でも撃破すると共有武技CDを3短縮
  - 強い敵1体を殴るより、あえて群れへ踏み込みまとめて倒す価値が生まれる
- 断界歩
  - 崩し斬りで敵予兆を中断すると共有武技CDを2短縮
  - さらに反撃好機を0.7秒延長
  - 危険な赤予兆へ逃げるだけでなく、殴りに行く型になる

槍
- 二段退き
  - 退き突き後、安全な床が続いていれば通常1マスから最大2マス後退
  - 攻撃しながら距離を大きく作り直す
- 串刺し律
  - 貫突で2体以上に命中すると、最後に当たった生存通常敵を1行動よろめかせる
  - 敵を列へ誘導する価値を増やす

弓
- 分岐牽制
  - 牽制射命中時、対象2マス以内に別の通常敵がいれば弱い矢が分岐
  - 分岐先にも低ダメージ + 1行動足止め
  - 一発を単体だけに使う制御技から、敵集団のテンポを崩す技へ変化
- 交差連射
  - 連射の2射目は可能なら1射目とは別の敵へ飛ぶ
  - 単体DPSより複数方向の圧力管理を優先する型

杖
- 砕氷火花
  - 火花の中心対象が凍結中なら、その凍結を消費
  - 半径2程度へ砕氷追加爆発
  - 氷環 → 火花という明確な生成/消費コンボが成立
- 永久氷環
  - 氷環の凍結を1行動 → 2行動へ延長
  - 3体以上を同時に凍結すると共有武技CDを2短縮
  - 敵が多いほど制御ループを回しやすくなる

- 従来は自爆予兆を完遂した時だけ爆発していた
- v4.09ではプレイヤーや別の敵に倒された場合も、その死亡地点で必ず爆発
- 近接で雑に倒すと自分が巻き込まれる危険がある
- 逆に敵群へ隣接させて倒せば敵をまとめて巻き込める
- 爆風を受けた別の爆ぜ虫も死亡すればさらに爆発し、連鎖爆発が成立
- 爆ぜ虫の爆風は隣接した爆薬樽も起爆
- 爆薬樽 → 爆ぜ虫 → 別の爆ぜ虫 → 樽のような環境連鎖も発生可能
- 爆ぜ虫の「爆ぜ」エリート変異は死亡爆発と二重発火しないよう処理を分離
- 連鎖爆発中に既に爆発中の爆ぜ虫を再撃破しないよう再入防止を追加

爆薬樽

- 敵を樽の近くへ誘導してから起爆する行動を探索結果へ残せる

観戦・配信フィードバック
- 敵利用ダメージ時は対象上へ「事故 -N」
- 敵利用撃破時は「TURNED」
- 約1.8秒以内に連続して敵利用撃破すると「CHAIN ×2 / ×3...」
- 連鎖時は「利用連鎖 ×N」の通知を表示
- 細かいダメージ計算を知らない視聴者でも「敵の攻撃で敵を倒した」ことが分かる
- 敵の攻撃予兆へ別の敵が巻き込まれている場合、その敵へ小さな橙色枠を表示
- 射線・突進・爆発・盾打ち・飛びかかりで巻き込み候補を視覚化
