深淵樹迷宮 v3.12.1.1 ADVENTURE AUDIO

HP・気力バー修正
原因
- iPhone用HUDではバー内部をspan要素で描画していた
- 塗り部分へdisplay:blockが指定されていなかった
- widthとheightが見た目へ反映されず、暗い背景だけが表示される場合があった

修正
- 塗り部分をblock要素として描画
- 横幅と高さを明示
- トラックの背景と枠を強化
- 発光を弱く追加
- 残量変化へ短いアニメーションを追加

HPの色
- 51〜100%：緑
- 26〜50%：橙
- 0〜25%：赤・弱い点滅

気力の色
- 26〜100%：青
- 0〜25%：黄橙

通常表示
- 通常HUDのHPバーは赤系
- 通常HUDの気力バーは青系
- iPhone専用HUDと通常HUDの両方へ色を保証

BGMの方向変更
以前
- Dドリアン寄り
- Fナチュラルを含む短調的な笛
- 長い低音ドローン
- 灯台82 BPM
- 通常探索96 BPM
- 地下墓所は大きく低く移調

修正後
灯台・タイトル
- Dメジャー寄り
- 98 BPM
- 上昇する笛の旋律
- 明るい3音アルペジオ
- 軽いフレームドラム
- 低音ドローンを約半分以下へ抑制

通常探索
- Dメジャー寄り
- 108 BPM
- 6/8拍子の旅歩き
- 小節中央にも短い弦を追加
- 笛が上へ抜ける旋律
- 軽い移動用ドラムを毎小節追加
- 古き石廊も通常時は長調を維持

危険時・番人戦・死亡
- 短調寄りの別音階を維持
- 危険が発生した時だけ緊張感を出す
- HP回復や危険解除後は明るい探索曲へクロスフェード

BGM表示名
- 灯台への序奏 → 旅立ちの灯台
- 灯台の炉辺 → 灯火と旅支度
- 深淵の旅路 → 緑風の冒険路
- 地下墓所 → 古き石廊
- 炉心 → 火の工房
- 霜洞 → 白銀洞
- 菌窟 → 光茸の小径

音響安定化
- 2レーンのクロスフェードを維持
- BGMタイマー1本制限を維持
- 効果音22音制限を維持
- バックグラウンド停止・復帰を維持
- 音量設定とON/OFF設定を維持

ゲームバランス
