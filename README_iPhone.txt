深淵樹迷宮 v3.10.9.1 SHORTCUT STAIR FIX

不具合
- 古い昇降路の端点が階層階段と同じ部屋中央に生成されることがあった
- v3.10.6.1以降、階段上の対象処理を優先する仕様により、重なった昇降路が先に発動
- 階段へ降りられず、以前とは逆に昇降路だけ使用できる状態になっていた

新規生成
- 古い昇降路は階段と同じマスへ生成しない
- プレイヤー開始位置とも重ねない
- 敵、アイテム、罠、特殊地点、事件、環境物、遺骸とも重ねない
- 他の昇降路端点とも重ねない
- 部屋中央が使用できない場合は近くの安全な床へ配置
- 原則として階段と昇降路は隣接または近接した別マスになる

既存セーブ
- 読み込み時に階段と重なった昇降路を検索
- 階段の隣から近い順に安全な床を探す
- 見つかった端点を自動移設
- 移設した数を探索ログへ表示
- 移設結果をセーブへ保存

重複が残る特殊ケース
地形に空きがなく移設できない場合も、どちらか一方を失いません。

中央ボタン
- 未回収物あり：回収 N
- 階段のみ：階段
- 階段と昇降路が重複：階段/昇降路

選択画面
- 階段を使う：次の階層へ進む
- 古い昇降路を使う：現在階層の反対側端点へ移動
- 戻る：何もせず閉じる
- 選択画面を開いただけではターンを消費しない

優先順位
1. 階段上のアイテム・事件・特殊地点・罠を処理
2. 重複していれば階段か昇降路を選択
3. 階段を選んだ場合は昇降路を発動せず降下
4. 昇降路を選んだ場合だけ同じ階層内を移動

安全処理
- 階段降下処理から古い昇降路の自動発動を除去
- 階段上の回収処理から古い昇降路の自動発動を除去
- 通常床の昇降路は従来どおり踏むと使用
- 移動先が同じ座標になった壊れた昇降路は発動しない

旧セーブ互換
- セーブ形式の変更なし
- 現在階層、装備、姿、倉庫、携行糧、迷宮反応などを維持
- 階段上に立った状態のセーブにも即時適用
