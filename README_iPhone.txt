外套色
- 初期から解放できる低価格色
- 中盤向けの高価格色
- 100〜720欠片を要求する超高額色
- 色は能力に影響せず、完全な自己表現用
- 解放後は何度でも無料で変更可能

輪郭
- 初期輪郭
- 第5・10・15・20層番人の確定姿片
- 条件達成後に欠片で購入する輪郭
- 条件が伏せられた秘密輪郭
- 番人から完全な運で入手する激レア・超激レア・神話級輪郭

紋章
- 胸、頭上、肩、周囲へ表示される装飾
- 条件達成後の欠片解放
- 秘密条件解放
- 番人の純運ドロップ
- 輪郭や外套色と独立して選択可能

秘密条件
例
- 到達深度
- 累計討伐数
- 深淵研究の合計
- 死亡経験
- 事件記録
- 武器熟練
- 進路熟練
- 行動傾向
- 深層適応数

条件未達成
- 名称と説明を「???」で秘匿

- 初めて判明した時はログへ通知

番人の純運ドロップ
激レア
- 基本4%
- 深度で最大約7%まで上昇

超激レア
- 基本1.2%
- 深層で最大約2.4%まで上昇

神話級
- 基本0.3%
- 最深部で最大約0.7%まで上昇

- 天井・確定交換なし
- 条件を満たした候補の中から抽選
- 高い等級の候補を全取得した後は、低い等級へ抽選を繰り下げ
