目的
- 「探索で偶然見つける」→「失いたくない」→「生還する」→「灯台で開ける」という感情の波を追加
- 単純な報酬量増加ではなく、期待・緊張・開放・余韻を分離する

封印遺物
- 通常敵から極低確率
- エリートは約3.8%
- 宿敵は約14%
- 番人は約30%
- 未発見状態では次に倒す番人が初回の封印遺物を必ず提示
- 特異室制圧後にも低確率で追加出現
- 最大3個まで携行
- 探索中は開封不可
- 死亡すると携行中の封印遺物はすべて喪失
- 生還すると灯台の「封印遺物」へ永久保存

封印の外見
- 灰封：通常敵由来
- 紫脈封：変異個体・特異室由来
- 黒金封：宿敵・番人由来
- 色は期待度の差を示すだけで、中身そのものは開封まで見えない
- 封印は入手順に開けるため、黄金残響を特定の封印へ任意に当てるリセマラを防止

灯台開封
- 開封時に短い静止・脈動演出を挟み、その後に報酬を公開
- 装備報酬は灯台調律済み・鑑定済み・保護状態で倉庫へ入る
- 倉庫が20/20で装備報酬になる封印は、誤消失防止のため開封できない

報酬層
- 希少装備
- 選別遺装：複数候補を内部抽選して良い方
- 伝説装備
- 魂還石
- 深層遺宝：極低確率。深度+3相当で生成した伝説候補3つの中から最良を採用し、専用名称を付与
- 各開封で少量の深淵の欠片も獲得

黄金残響（ゲーム内救済）
- 伝説以上が出なかった開封で +1
- 7/7になると次の開封は伝説以上を保証
- 伝説以上が出ると0へ戻る
- 灯台に進捗を常時表示
- 課金、期限、ログイン日課、取り逃し要素は無し

探索結果
- 封印遺物の発見数
- 生還時の持ち帰り数
- 死亡時の喪失数
を記録

既存セーブ
- meta.sealedRelics / relicFortune が無い場合は自動初期化
- 進行中の旧探索には sealedRelics=[] を補完
- 既存の装備・倉庫・銘装・研究・遺響・生態・深脈などは変更しない

- 開錠は中央ボタンが「開錠」へ変化し、押すと開始

- 開錠中は移動・攻撃・武器技・構え・集中・治癒薬など通常行動を行えない

- メニュー・敵詳細・装備画面などゲーム時間停止UIを開いた場合は、再封印タイマー自体は停止。ただし進行中の開錠は解除される

v4.07 SKILL MUTATIONS
- v4.06で「構え / 主武技 / 治癒 / 副武技」というリアルタイム戦闘動詞を作ったため、次はハクスラの中心である「装備を拾うと戦い方そのものが変わる」を実装

生成ルール
- 戦技変質は武器にだけ付与
- 通常ルールでは魔法武器55%、希少・伝説武器100%
- 第1〜5層のリアルタイム試作中に生成される魔法以上の武器は、システム評価をしやすくするため100%で1つ付与
- 希少以上へ昇格した武器に戦技変質が無い場合は自動で1つ補完
- コモン武器には付与しない
- スターター武器には付与しないため、変質武器を拾った時に「装備更新で戦い方が変わった」と比較できる
- 一つの武器には現在1種類だけ付く

剣
- 血旋連舞
  - 旋撃で2体以上を巻き込み、1体でも撃破すると共有武技CDを3短縮
  - 強い敵1体を殴るより、あえて群れへ踏み込みまとめて倒す価値が生まれる
- 断界歩
  - 崩し斬りで敵予兆を中断すると共有武技CDを2短縮
  - さらに反撃好機を0.7秒延長
  - 危険な赤予兆へ逃げるだけでなく、殴りに行く型になる

槍
- 二段退き
  - 退き突き後、安全な床が続いていれば通常1マスから最大2マス後退
  - 攻撃しながら距離を大きく作り直す
- 串刺し律
  - 貫突で2体以上に命中すると、最後に当たった生存通常敵を1行動よろめかせる
  - 敵を列へ誘導する価値を増やす

弓
- 分岐牽制
  - 牽制射命中時、対象2マス以内に別の通常敵がいれば弱い矢が分岐
  - 分岐先にも低ダメージ + 1行動足止め
  - 一発を単体だけに使う制御技から、敵集団のテンポを崩す技へ変化
- 交差連射
  - 連射の2射目は可能なら1射目とは別の敵へ飛ぶ
  - 単体DPSより複数方向の圧力管理を優先する型

杖
- 砕氷火花
  - 火花の中心対象が凍結中なら、その凍結を消費
  - 半径2程度へ砕氷追加爆発
  - 氷環 → 火花という明確な生成/消費コンボが成立
- 永久氷環
  - 氷環の凍結を1行動 → 2行動へ延長
  - 3体以上を同時に凍結すると共有武技CDを2短縮
  - 敵が多いほど制御ループを回しやすくなる

- 永久氷環など凍結2段階：8世界パルス = 約1.68秒
- 高速敵0.42秒 / 遅い敵0.84秒のどちらへ使っても、同じ状態異常なら同じ世界時間だけ止まる
- 「高速敵だから凍結が一瞬で1行動消費される」「遅い敵だけ状態異常が倍近く長い」といった差を撤廃
- 集中中は世界時間が遅くなるため、凍結・よろめき・絡み根も実時間では長くなる
- 敵詳細へ「凍結 0.6秒」「よろめき 0.4秒」「絡み根 0.5秒」のような残り時間を表示

既存セーブ互換
- 旧保存にstagger / frozen / terrainSlowの残り回数がある場合、最初の敵処理時に新しい世界時間へ自動移行
- 世界時間窓そのものはランタイム管理し、performance.nowなど再読込で壊れる絶対時刻をactive saveへ保存しない
- フロア移動時は一時的な構え / 制御状態をクリアし、新階層紹介 + 0.8秒先行猶予から安全に開始
- active save schema version=4は変更なし

敵AI基準

- 行動範囲外へ出た場合は巣方向へ戻ろうとする
- 通路が塞がった時や立ち止まった時は次の進行方向を変える
- 既存の異種族同士の自律戦闘は生息移動より優先

- role: front

穴獣
- role: flank
- 1〜2マス圏で空いている側面を強く優先
- 同じ側に敵がいるほど大きく減点
- 現在いる側から別方向へ回り込める移動に加点

穿ち獣
- role: flank
- 直線2〜5マスで突進可能なら従来の突進を最優先
- 突進線が作れない時は穴獣と同じく側面へ回る
- 「横へ回る → 縦横が揃う → 突進予兆」という流れが起きやすい

骨術師
- role: ranged
- 3〜5マス距離を好む
- プレイヤーへ直線射線が通る位置へ強く加点
- 隣接は大きく減点
- 射線がない場合に単純直進せず、横へ動いて射撃位置を探す
- 射線成立後は従来の骨弾予兆・敵誤射システムへ接続

墓鐘司祭
- role: ranged/support
