深淵樹迷宮 v3.21.1 BOOT RECOVERY

3.21.1 起動復旧
- 3.21.0で欠落していた </style> を復元し、画面が暗いまま何も表示されない不具合を修正
- 起動処理を例外保護し、異常時はタイトル画面に「起動を復旧する」を表示
- 復旧操作はService Worker/配信キャッシュだけを更新し、localStorageのセーブデータは削除しない
- 封印遺物・黄金残響・既存進行データの仕様は3.21.0から維持

目的
- 「探索で偶然見つける」→「失いたくない」→「生還する」→「灯台で開ける」という感情の波を追加
- 単純な報酬量増加ではなく、期待・緊張・開放・余韻を分離する

封印遺物
- 通常敵から極低確率
- エリートは約3.8%
- 宿敵は約14%
- 番人は約30%
- 未発見状態では次に倒す番人が初回の封印遺物を必ず提示
- 特異室制圧後にも低確率で追加出現
- 最大3個まで携行
- 探索中は開封不可
- 死亡すると携行中の封印遺物はすべて喪失
- 生還すると灯台の「封印遺物」へ永久保存

封印の外見
- 灰封：通常敵由来
- 紫脈封：変異個体・特異室由来
- 黒金封：宿敵・番人由来
- 色は期待度の差を示すだけで、中身そのものは開封まで見えない
- 封印は入手順に開けるため、黄金残響を特定の封印へ任意に当てるリセマラを防止

灯台開封
- 開封時に短い静止・脈動演出を挟み、その後に報酬を公開
- 装備報酬は灯台調律済み・鑑定済み・保護状態で倉庫へ入る
- 倉庫が20/20で装備報酬になる封印は、誤消失防止のため開封できない

報酬層
- 希少装備
- 選別遺装：複数候補を内部抽選して良い方
- 伝説装備
- 魂還石
- 深層遺宝：極低確率。深度+3相当で生成した伝説候補3つの中から最良を採用し、専用名称を付与
- 各開封で少量の深淵の欠片も獲得

黄金残響（ゲーム内救済）
- 伝説以上が出なかった開封で +1
- 7/7になると次の開封は伝説以上を保証
- 伝説以上が出ると0へ戻る
- 灯台に進捗を常時表示
- 課金、期限、ログイン日課、取り逃し要素は無し

探索結果
- 封印遺物の発見数
- 生還時の持ち帰り数
- 死亡時の喪失数
を記録

既存セーブ
- meta.sealedRelics / relicFortune が無い場合は自動初期化
- 進行中の旧探索には sealedRelics=[] を補完
- 既存の装備・倉庫・銘装・研究・遺響・生態・深脈などは変更しない
