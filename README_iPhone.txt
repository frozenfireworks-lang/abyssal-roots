深淵樹迷宮 v3.8.8 FIELD SALVAGE

今回の目的
- 装備枠が満杯になったとき、単に拾えない状態ではなく「整理と選択」の遊びへ変える

新システム：現地分解
- 荷物内の不要装備を「現地素材」へ分解可能
- 通常1 / 魔法3 / 希少7 / 伝説15素材が基本
- アイテムレベルと装備絆によって分解量が少し増加
- 希少・伝説装備は取得時に自動保護
- 保護した装備は分解不可

新システム：即席工房
- 荷造り改善：素材を使い、現在の探索だけ荷物上限+2（最大3回）
- 武器仮補強：現在の探索だけ攻撃+1（最大3回）
- 防具仮補強：現在の探索だけ防御+1（最大3回）
- 鑑定は鑑定紙片、現地素材2、または8Gから支払い可能

整理機能
- 推奨度 / レア度 / 部位 / アイテムレベル / 装備絆で並び替え
- 装備を個別に保護・保護解除
- 保護されていない通常装備を一括分解
- 荷物満杯時は装備画面を自動で開く
- 足元に残った装備を、整理後にその場で拾い直せる
- 帰還時、余った現地素材5ごとに深淵の欠片1へ変換

維持
- 空腹4段階
- 攻撃予兆と範囲表示
- 総合ビジュアルと探索者アイコン成長
- 旧セーブデータ自動移行
