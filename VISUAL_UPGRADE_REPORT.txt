変更内容
1. 迷宮メイン画面のタイル基準を 22px → 28px に変更。
2. 論理Canvasサイズを 374x462 → 476x588 に変更。
3. 実Canvasバッファを 748x924 → 952x1176 に変更。
4. Canvas初期化時に width / height / aspect ratio を定数から同期。
5. 既存の nearest-neighbor 系描画を維持し、単純なぼやけ拡大を回避。
6. 標準品質の粒子数を微減し、iPhoneでの負荷増を抑制。

見た目への効果
- 1タイルあたりの描画余白が増え、床・壁・デカール・キャラクターの細部がより読み取りやすくなります。
- 既存のレトロ感は保ちつつ、画面全体の解像感と情報密度が向上します。
- v4.27で追加した視覚効果が、より潰れずに見えるようになります。

パフォーマンスへの影響
- タイルあたりの描画面積は増加します。
- 一方で、描画オブジェクト数やゲームロジックは増やしていないため、影響は中程度です。
- 粒子数を微調整して、iPhone実機での体感悪化を起こしにくくしています。

次段階の推奨
- 敵スプライト全種の 28px 前提描き込み強化
- 光源ごとの色分離
- UI全画面の完全統一
